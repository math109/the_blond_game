# The Blonde

Jogo de terror psicológico top-down sobre bullying e a lenda da Loira do Banheiro, ambientado na UNIFOR.
Feito em **Godot 4.7** (renderer Compatibility).

## Como abrir
1. Godot 4.7 → **Import** → escolha o `project.godot` desta pasta.
2. **F5** para jogar.

## Controles
| Ação | Teclado | Gamepad |
|---|---|---|
| Andar | WASD / setas | analógico |
| Correr / agachar | Shift / Ctrl | RB / LB |
| Interagir | E | A |
| Lanterna | F | X |
| Celular | Tab | Y |

## Organização
- `PLANO.md` — o cronograma das aulas.
- `aulas/` — uma explicação por aula, linha por linha.
- `cenas/` — cenas do Godot (`.tscn`). `scripts/` — código (`.gd`).
- `assets/` — cenários, personagens, itens, fontes e áudio (`musica`, `ambiente`, `sfx`).
